# Vibe Kit 3.0

Read `AGENTS.md` and follow it. Work only within the active phase contract. Never change the phase contract, governance, or acceptance criteria yourself. Run and report actual checks; create a PR but never review or merge your own PR. Merging follows the delegated delivery workflow in `AGENTS.md`.

## Output style
- Be terse. Lead with the result; no preamble, recap, or restating the request.
- Use short bullets or a small table. No paragraphs of rationale unless asked.
- Final report: branch/commit, checks run + result, PR link, blockers. One line each.
- Ask only when blocked on an owner-only action; otherwise act.
